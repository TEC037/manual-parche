# M@nü4I D3l P4rch3 - Sitio GitHub Pages

Plataforma web para consulta y difusión comunitaria de la guía táctica **M@nü4I D3l P4rch3**, con visor en línea, descarga directa y acceso al registro oficial de membresías del **Movimiento Político Pacto Histórico**.

---

## Contenido del Repositorio

- `index.html`: Interfaz web con visor PDF integrado, diseño responsivo, botones de descarga y redirección al registro del Pacto Histórico.
- `M@nü4I D3l P4rch3.pdf`: Archivo del manual listo para visualización y descarga.
- `qr.png`: Código QR oficial para compartir y difundir el enlace.
- `.nojekyll`: Garantiza la entrega directa de todos los recursos en GitHub Pages.

---

## Despliegue en GitHub Pages

1. En tu repositorio en GitHub, ve a **Settings** > **Pages**.
2. En **Build and deployment** > **Source**, selecciona `Deploy from a branch`.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Haz clic en **Save**.

El sitio estará disponible en:
`https://TU-USUARIO.github.io/manual-parche/`
